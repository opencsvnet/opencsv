Three steps when the link opens

The beta is intentionally narrow: one signet-only Test USD product, consumer send and receive, and evidence you can inspect.

Step 1

Install TestFlight

Use Apple’s TestFlight app on an iPhone running a supported iOS version.

Step 2

Join OpenCSV Demo

Open the public invitation, install the beta, and register a disposable test account.

Step 3

Send Test USD

Fund the signet fee reserve, receive test assets, then send them in a conversation.

What you are testing

Every important boundary is explicit. This is a public research beta, not money and not an official Signal release.

Testnet only

Test USD is permanently bound to Bitcoin signet. It has no redemption promise or monetary value.

No arbitrary BTC sends

The Bitcoin wallet exists only to pay OpenCSV protocol fees and perform protocol-safe fee bumps.

Verifiable evidence

Receipts expose transaction identity, proof state, observer results, and confirmed-chain evidence.

Unofficial prototype. OpenCSV Demo is an independently built AGPL fork for testing OpenCSV. It is not produced, endorsed, or supported by Signal Messenger, LLC. Third-party builds do not receive Signal’s production push-notification entitlement, so background delivery may be unreliable during this beta.

Before you join

  • Use a test account and test assets. Do not rely on this beta for important messages or funds.
  • Expect builds to expire and data formats to change while recovery and crash-resume gates are completed.
  • Keep the app foregrounded during payment demonstrations when immediate message delivery matters.
  • Review the corresponding source, paper, and evidence journal.
